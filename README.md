# CocoaPods-Practice

A practical project for getting started with CocoaPods

## Stack & Dependencies
- Swift / SwiftUI (iOS 15.0+)
- MVVM
- CocoaPods
- [Kingfisher](https://github.com/onevcat/Kingfisher)

## Key Learning Focus
- Creating a project and adding the Kingfisher library to it using CocoaPods
- Setting up a clean, scalable project structure

## How to Run
1. Clone the repository
2. Run 'pod install' in the project directory
3. **Important:** Open 'testManagers.xcworkspace' (not '.xcodeproj')
